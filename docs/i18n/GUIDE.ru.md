# Руководство TheNewMiner

Всё, что выходит за рамки первого запуска: проверка загруженных файлов, повседневная работа в Linux, Windows и HiveOS,
обновления, что делать, если майнинг не идёт, и частые вопросы. Загрузки и быстрый старт находятся на
[главной странице](README.ru.md); для проблем в Windows есть отдельная страница:
[Устранение неполадок в Windows](WINDOWS-TROUBLESHOOTING.ru.md).

Zip-архив для Windows — всё в одном: он уже содержит Linux-майнер, поэтому вам нужен только этот zip. Положите пакет(ы)
и [`SHA256SUMS`](https://github.com/ngasuka855/TheNewMiner/raw/v0.1.47/SHA256SUMS) в одну папку, затем выполните:

```bash
# Linux (--ignore-missing: проверяются только те пакеты, которые вы скачали)
sha256sum -c --ignore-missing SHA256SUMS
# macOS
shasum -a 256 -c --ignore-missing SHA256SUMS
```

```bat
:: Windows (Командная строка): сравните вывод с SHA-256 из таблицы выше
certutil -hashfile TheNewMiner-v0.1.47-windows-wsl2-r3.zip SHA256
```

Для каждого файла должно быть выведено `OK` (в Windows — те же 64 символа, что и в таблице). Если сумма не совпадает,
не используйте этот файл.

## Linux

```bash
tar -xJf TheNewMiner-v0.1.47-linux-x86_64-sealed.tar.xz
cd thenewminer
./thenewminer -u <YOUR_WALLET> -p '<YOUR_POOL_PASSWORD>' -w rig-01 --background
```

| Команда | Что делает |
|---|---|
| `./thenewminer -u <YOUR_WALLET> -p '<YOUR_POOL_PASSWORD>' -w rig-01 --background` | Первый запуск: устанавливает всё необходимое, затем майнит в фоновом режиме |
| `./thenewminer --background` | Последующие запуски: ваши настройки запоминаются |
| `./thenewminer` | Майнинг на переднем плане (Ctrl+C останавливает) |
| `./thenewminer --logs` | Наблюдение за майнером (Ctrl+C закрывает просмотр; майнинг продолжается) |
| `./thenewminer --status` | Идёт ли майнинг, последний хешрейт и принятые / отклонённые шары; после остановки — почему майнер остановился и как это исправить |
| `./thenewminer --stop` | Остановить майнинг |
| `./thenewminer --help` | Все параметры |

- `-u` — ваш адрес кошелька TensorCash, `-p` — ваш пароль от пула, `-w` — имя воркера, которое отображается на пуле
  (по умолчанию: имя хоста машины; 1–64 символа: латинские буквы, цифры, `_`, `-` или `.`).
- Адрес кошелька проверяется до того, как что-либо запустится: адрес с опечаткой (его контрольная сумма не совпадает)
  или адрес из примера отклоняется с объяснением, что не так.
- Пароль от пула: 6–128 символов, любые видимые символы, без пробелов. В командной строке всегда заключайте его в
  одинарные кавычки, например `-p 'my$pass!'` (символ `'` внутри одинарных кавычек записывается как `'\''`).
- Настройки запоминаются в `thenewminer/.miner/` (файл с паролем доступен для чтения только вам). Кошелёк и пароль
  сразу же убираются из командной строки, поэтому они не видны в `ps` (ваша оболочка всё же может сохранить команду в
  своей истории).
- При первом запуске на машине с одной видеокартой майнер проверяет кошелёк и пароль на пуле **до** загрузки модели,
  поэтому опечатка обнаруживается за секунды (риг с несколькими GPU обнаруживает её, когда начинается майнинг). Если пул
  отклоняет их, майнер сообщает об этом и останавливается: проверьте их и запустите майнер снова с `-u` и `-p`.
- При первом запуске майнер скачивает модель (около 8.1 GiB, однократно), устанавливает GPU-движок для вашей видеокарты
  и выполняет самопроверку на карте, после чего начинает майнить. Строки вида `[ RATE] ... N/s` означают, что идёт
  майнинг. Лог находится в `thenewminer/.miner/thenewminer.log`.
- Стандартная Ubuntu 22.04 / 24.04 (включая Ubuntu в WSL) уже содержит все библиотеки, нужные майнеру, поэтому ничего не
  устанавливается. Если какой-то не хватает (образы Docker, минимальные системы), первый запуск в Ubuntu, Debian и HiveOS
  перечисляет её и устанавливает через `apt` (нужны sudo или root); в других системах майнер называет её, чтобы вы
  установили её сами.
- Риги с несколькими GPU: поддерживаются, майнит каждая видеокарта; этот релиз тестировался с одной видеокартой на машину.
- В Docker и других контейнерах с малым объёмом общей памяти майнер запускает свои программные файлы из
  `thenewminer/.miner/run/` на диске и сообщает об этом. Чтобы выбрать другую папку, запустите его так:
  `TNPSEAL_RUNTIME_BASE=<folder> ./thenewminer` (папка, в которую можете записывать только вы: `chmod 700 <folder>`).
- **Обновление:** `./thenewminer --stop`, распакуйте новый пакет в то же место (он распаковывается в `thenewminer/` и
  сохраняет `thenewminer/.miner/` с вашими настройками и моделью), затем снова запустите майнер. Если старая версия ещё
  работает, новая отказывается запускаться и просит сначала остановить старую. Если же распаковать пакет в новую папку,
  он найдёт модель старой версии (тот же размер и SHA-256) и использует её повторно: второй загрузки 8.1 GiB не будет.
  Там снова укажите `-u -p -w`.

### Если майнинг не идёт

`./thenewminer --status` сообщает, почему майнер остановился и как это исправить. Самые частые сообщения:

| Вы видите | Что делать |
|---|---|
| `bash: ./thenewminer: Permission denied` | Папка не позволяет запускать программы (монтирование `noexec`, например некоторые `/tmp`, или USB-флешка). Распакуйте пакет в домашнюю папку: `cd ~ && tar -xJf <the package>.tar.xz && cd thenewminer` |
| `this package is on a FAT (vfat) drive` (или exFAT / NTFS, или `Windows (DrvFs, 9p)`: диск Windows, например `/mnt/d` в WSL) | Такой диск не может хранить приватные настройки майнера (режим 600). Вставьте строку `mkdir -p ~/thenewminer && cp -a ...`, которую выводит майнер: она копирует папку в вашу домашнюю папку Linux и запускает майнер там |
| `this system has no xz` | `sudo apt-get install -y xz-utils` (от root — без `sudo`), затем запустите снова |
| `This system is missing what TheNewMiner needs` | Выполните строку `sudo apt-get install -y ...`, которую выводит майнер, затем запустите снова |
| `No NVIDIA GPU found on this machine` | Видеокарта NVIDIA не обнаружена. Проверьте, что карта правильно установлена и к ней подключено питание; на облачной машине выберите машину с GPU NVIDIA |
| `NVIDIA driver ... is too old` | Установите названный драйвер (580 или новее), перезагрузите компьютер и запустите снова (см. «Обновите драйвер NVIDIA» ниже) |
| `the pool rejected the wallet / password` | Проверьте `-u` и `-p` и что аккаунт существует на сайте пула, затем выполните `./thenewminer -u <YOUR_WALLET> -p '<YOUR_POOL_PASSWORD>' --background` |
| `no download source answered` | Загрузка модели не может подключиться к интернету. За прокси: `https_proxy=http://<HOST>:<PORT> ./thenewminer --background`; или скопируйте модель (см. «Модель уже есть?» ниже) |
| `cannot reach the pool` / `pool disconnected` | Проверьте подключение к интернету, DNS и что брандмауэр разрешает исходящие соединения TCP 443; если ваша сеть блокирует пул, используйте `--proxy` (см. «Прокси» ниже). Майнер переподключается сам |

### Запуск после перезагрузки (необязательно)

Майнер не запускается сам после перезагрузки (в HiveOS это делается за вас). В Linux добавьте либо строку в `crontab`:

```bash
crontab -e      # затем добавьте эту строку (с вашей папкой):
@reboot cd /home/<YOU>/thenewminer && ./thenewminer --background
```

либо пользовательский сервис systemd (один раз выполните `loginctl enable-linger <YOU>`, чтобы он запускался без входа
в систему):

```ini
# ~/.config/systemd/user/thenewminer.service, затем: systemctl --user enable --now thenewminer
[Unit]
Description=TheNewMiner
After=network-online.target
[Service]
WorkingDirectory=%h/thenewminer
ExecStart=%h/thenewminer/thenewminer
ExecStop=%h/thenewminer/thenewminer --stop
Restart=on-failure
RestartSec=60
RestartPreventExitStatus=77
[Install]
WantedBy=default.target
```

Код выхода 77 означает, что пул отклонил кошелёк / пароль: перезапуск не поможет, поэтому сервис на этом
останавливается.

## Windows

1. Распакуйте весь архив `TheNewMiner-v0.1.47-windows-wsl2-r3.zip` (правый клик › «Извлечь все») куда угодно: в любую
   папку, на любой диск; пути с пробелами или китайскими символами допустимы. Не запускайте его из окна просмотра zip.
2. Дважды щёлкните **`TheNewMiner.bat`**.
   - **В первый раз:** ОДНО окно сначала запрашивает данные вашего аккаунта на пуле: адрес кошелька (начинается с
     `tc1`; его контрольная сумма проверяется, а показанный пример — не настоящий кошелёк), пароль от пула (6–128
     символов, любые видимые символы, без пробелов) и имя воркера (подставляется имя компьютера). Кнопка OK остаётся
     серой, пока все три поля не заполнены правильно. После OK и «Да» больше ничего не спрашивается: программа проверяет
     Windows, драйвер и диск, при необходимости включает WSL2 (один запрос прав администратора; однократно может
     потребоваться перезагрузка, после чего установка продолжится сама), показывает, куда будут сохранены данные,
     создаёт собственную среду Linux (WSL), устанавливает встроенный майнер, скачивает модель, затем начинает майнить.
     Без рабочего стола (по SSH) те же вопросы задаются в консоли.
   - **Каждый следующий раз:** дважды щёлкните — и майнинг сразу начнётся с сохранёнными настройками. Также создаётся
     ярлык «TheNewMiner» на рабочем столе. Если дважды щёлкнуть, когда майнинг уже идёт, он сообщит об этом и покажет лог.
   - **Если установка останавливается,** окно сообщает, на каком шаге и что делать, и `TheNewMiner.bat` показывает это
     снова. См. [Устранение неполадок в Windows](WINDOWS-TROUBLESHOOTING.ru.md).

Повседневные команды (откройте командную строку в распакованной папке):

| Команда | Что делает |
|---|---|
| `TheNewMiner.bat` | Установка при необходимости, затем майнинг в этом окне (закрытие окна останавливает майнинг) |
| `TheNewMiner.bat background` | Майнинг без окна |
| `TheNewMiner.bat logs` | Наблюдение за майнером (Ctrl+C закрывает просмотр; майнинг продолжается) |
| `TheNewMiner.bat status` | Работает ли майнер, и последние значения хешрейта |
| `TheNewMiner.bat stop` | Остановить майнинг |
| `TheNewMiner.bat setup` | Заново ввести кошелёк / пароль / имя воркера (Cancel оставляет их без изменений) |
| `TheNewMiner.bat uninstall` | Удалить майнер, его папку с данными и ярлык (сначала спрашивает подтверждение) |

- **Где хранятся данные:** майнер и модель находятся в папке данных, выбранной при первой установке (по умолчанию
  `TheNewMinerData` в корне диска, на который вы распаковали архив, например `D:\TheNewMinerData`), а не в распакованной
  папке. Там нужно около 20 GB свободного места. Чтобы выбрать другую папку: `TheNewMiner.bat setup -DataDir <folder>`.
- **Ubuntu:** установка ставит Ubuntu 24.04 с помощью `wsl --install`. Если эта загрузка не может подключиться,
  установка скачивает официальный WSL-образ Ubuntu `ubuntu-24.04.5-wsl-amd64.wsl` с публичного зеркала в Китае
  (Tsinghua TUNA, затем USTC, затем Aliyun) и использует его, только если его SHA-256 в точности равен
  `bb415d824822c4b878125729af451a5d18fb13d1cf5cbed9a7393ad64ac6039e`.
- Если пул отклоняет кошелёк или пароль, окно сообщает об этом и майнинг останавливается: выполните
  `TheNewMiner.bat setup`, чтобы ввести их заново.
- **Обновление:** распакуйте новую версию куда угодно и дважды щёлкните её `TheNewMiner.bat`. Он найдёт установленный
  майнер, сохранит ваши настройки и модель и установит новую версию без лишних вопросов. Установка, сделанная более
  ранней версией или вручную внутри другого дистрибутива WSL (например, `Ubuntu-24.04`), находится и обновляется там, где
  она есть: без второй установки, без новой Ubuntu, без повторной загрузки модели. Если обновить её там невозможно,
  установка останавливается и объясняет причину. Старую папку можно удалить.
- **Удаление:** `TheNewMiner.bat uninstall`. Оно никогда не удаляет ваш собственный дистрибутив WSL.
- Комплект для Windows работает на английском языке.

## HiveOS (экспериментально)

Поддержка HiveOS является **экспериментальной** (с v0.1.45, которая работала на реальном риге HiveOS; изменения после
v0.1.46 на таком риге ещё не запускались). Она использует пакет custom-майнера для HiveOS `thenewminer-0.1.47.tar.gz`
(его SHA-256 указан в таблице в разделе «Проверка загруженных файлов»).

Быстрая настройка (импорт flight sheet):

1. **Wallets** (кошельки): добавьте кошелёк с монетой `TSC` и вашим адресом TensorCash (`tc1...`). Это нужно сделать
   один раз: в HiveOS должен быть выбран кошелёк `TSC`, а майнер использует адрес, который вы укажете во flight sheet.
2. Откройте [`hiveos/flightsheet-thenewminer.json`](../../hiveos/flightsheet-thenewminer.json) и скопируйте его
   содержимое. Замените `<YOUR_WALLET>` адресом своего кошелька (оставив `.%WORKER_NAME%` после него), а
   `<YOUR_POOL_PASSWORD>` — своим паролем от пула (в JSON символ `"` в пароле записывается как `\"`, а `\` — как `\\`).
   В HiveOS выберите Flight Sheets › **Import from clipboard**, вставьте содержимое, выберите свой кошелёк `TSC` и
   сохраните.
3. Примените flight sheet к своему ригу. Риг скачает пакет и начнёт майнинг.

Вместо этого можно настроить вручную: создайте flight sheet с Coin `TSC`, Wallet — ваш кошелёк `TSC`, Pool — "Configure
in miner", Miner — "Custom", нажмите **Setup Miner Config** и заполните:

| Поле | Значение |
|---|---|
| Miner name | `thenewminer` (заполняется автоматически из Installation URL) |
| Installation URL | `https://github.com/ngasuka855/TheNewMiner/raw/v0.1.47/thenewminer-0.1.47.tar.gz` |
| Hash algorithm | оставьте пустым |
| Wallet and worker template | `%WAL%.%WORKER_NAME%` |
| Pool URL | `tsc-wss.the-new.win` (игнорируется: пул встроен в майнер) |
| Pass | ваш пароль от пула |
| Extra config arguments | пусто или `--proxy <YOUR_PROXY>` (см. раздел «Прокси») |

- Имя воркера на пуле — это имя рига в HiveOS: используйте только латинские буквы, цифры, `_`, `-` или `.` (без
  пробелов), не более 64 символов. Чтобы использовать другое имя воркера, добавьте `-w <RIG_NAME>` в поле Extra config
  arguments.
- На диске HiveOS должно быть свободно около 12 GB для модели и майнера (проверьте командой `df -h /hive/miners`).
- Модель (около 8.1 GiB) скачивается один раз в `/hive/miners/custom/.thenewminer-models` и сохраняется при обновлении.
- Кошелёк и пароль передаются майнеру через переменные окружения, а не через его командную строку.
- **Если что-то не получается** (например, пул отклоняет кошелёк или пароль), лог майнера и панель HiveOS (dashboard)
  показывают причину, а риг повторяет попытку с растущими паузами (от одной до десяти минут). Исправьте flight sheet и
  примените его: это сразу перезапускает майнер.
- Логи: экран майнера в HiveOS (`miner` в shell рига) или `/var/log/miner/custom/custom.log`.
- **Обновление:** измените оба номера версии в Installation URL (например, `.../raw/vX.Y.Z/thenewminer-X.Y.Z.tar.gz`)
  и примените flight sheet. HiveOS выполняет установку, только когда меняется имя файла в URL.
- **Первый запуск** скачивает модель и устанавливает GPU-движок, что занимает несколько минут.
- **Модель уже есть?** Скопируйте её в `/home/user/` на риге до первого запуска (см. следующий раздел).

**Если риг не может подключиться к GitHub:** скачайте `thenewminer-0.1.47.tar.gz` на ПК (сверьте его SHA-256),
скопируйте его на риг и распакуйте туда, где HiveOS хранит пользовательские майнеры. Затем примените flight sheet как
обычно: HiveOS сообщит "Already installed" и не будет его скачивать. Имя файла должно быть ровно
`thenewminer-0.1.47.tar.gz` (браузер может добавить " (1)"), а Installation URL во flight sheet менять нельзя: HiveOS
сравнивает именно это имя.

```bash
# на ПК
scp thenewminer-0.1.47.tar.gz user@<RIG_IP>:/tmp/
# на риге, от root (Hive Shell или SSH, затем sudo -i)
mkdir -p /hive/miners/custom/downloads
mv /tmp/thenewminer-0.1.47.tar.gz /hive/miners/custom/downloads/
cd /hive/miners/custom && tar -xzf downloads/thenewminer-0.1.47.tar.gz
```

## Модель уже есть? Скопируйте её

Майнеру нужен один файл модели размером 8.1 GiB: `Qwen3-8B-Q8_0-full-v2.gguf` (`8709518112` байт, SHA-256
`408b955510e196121c1c375201744783b5c9a43c7956d73fc78df54c66e883d6`). Если он уже есть на этой машине или на другом
компьютере в вашей сети, скопируйте его, а не скачивайте заново.

Прежде чем что-либо скачивать, майнер ищет файл по точному имени и размеру: в своей папке моделей, в папках предыдущих
версий TheNewMiner, в вашей домашней папке (и на один-два уровня ниже неё или в папке `models` там), в
домашних папках внутри `/home`, в `/data`, `/mnt/*`, `/media/*`, `/opt`, `/srv`, `/workspace`, `/var/lib` и в кэшах
Hugging Face / ModelScope. Если там ничего не найдено, он до 20 секунд ищет в этих папках на том же диске (другие
подключённые диски проверяются только по имени) любой файл `.gguf` именно такого размера. Найденный файл используется
**только если его SHA-256 совпадает**; затем майнер создаёт на него ссылку (на том же диске) или копирует его в свою
папку моделей, так что каждая следующая версия сразу его находит. Можно также указать файл напрямую:
`./thenewminer --model /path/to/Qwen3-8B-Q8_0-full-v2.gguf`.

**Linux:** скопируйте файл в домашнюю папку, затем запустите майнер как обычно. С Mac или ПК в той же сети (в Windows 10
и 11 есть `scp` в PowerShell) замените `user` и `<MINER_IP>` логином и адресом вашего майнера:

```bash
# на самом майнере
cp /path/to/Qwen3-8B-Q8_0-full-v2.gguf ~/
# или с другого компьютера
scp Qwen3-8B-Q8_0-full-v2.gguf user@<MINER_IP>:~/
```

**HiveOS:** скопируйте файл в `/home/user/` на риге (логин SSH в HiveOS — `user`), затем примените flight sheet. Майнер
найдёт его там, проверит и сохранит рядом с пакетом (`/hive/miners/custom/.thenewminer-models`), поэтому новая версия
никогда не будет скачивать его заново. Диск HiveOS небольшой: сначала выполните `disk-expand`, если `df -h /hive/miners`
показывает меньше 12 GB свободного места.

```bash
scp Qwen3-8B-Q8_0-full-v2.gguf user@<RIG_IP>:/home/user/
```

**Windows:** после того как первый `setup` создал WSL-дистрибутив TheNewMiner, скопируйте в него файл из командной
строки Windows (замените `D:\Models` на папку, где лежит ваша копия). Если загрузка уже началась, закройте окно,
выполните эти команды, затем снова запустите TheNewMiner: он найдёт копию и пропустит загрузку. Копирование занимает
несколько минут и не показывает прогресс.

```bat
wsl -d TheNewMiner -u root -- mkdir -p ~/thenewminer/models
wsl -d TheNewMiner -u root -- cp /mnt/d/Models/Qwen3-8B-Q8_0-full-v2.gguf ~/thenewminer/models/
```

## Смена кошелька, пароля от пула или имени воркера

Пул навсегда привязывает каждый адрес выплат к его собственному аккаунту на пуле: страница пула
[tsc.the-new.win](https://tsc.the-new.win) называет адрес выплат TSC «永久绑定 · 不可修改» (привязан навсегда, изменить нельзя)
и указывает, что для смены нужно использовать новый адрес непосредственно в майнере. Поэтому для другого кошелька нужны
свой аккаунт на пуле и свой пароль от пула (сначала создайте их на странице пула). Если вы меняете пароль от пула на
странице пула, обновите его на каждом майнере. Пул не может восстановить забытый пароль.

**Linux:** остановите майнер, затем запустите его один раз с новыми настройками; они заменят запомненные:

```bash
./thenewminer --stop
./thenewminer -u <NEW_WALLET> -p '<PASSWORD>' -w <RIG_NAME> --background
```

Указывайте `-u` и `-p` вместе: только один из них не меняет запомненные кошелёк и пароль. Имя воркера можно изменить
отдельно: `./thenewminer -w <RIG_NAME> --background` (после `--stop`).

**Windows:** запустите `TheNewMiner.bat setup`. Откроется окно аккаунта с уже заполненным именем воркера; введите
кошелёк и пароль от пула, затем запустите майнер как обычно (двойной щелчок по `TheNewMiner.bat`).

**HiveOS:** отредактируйте flight sheet: укажите новый адрес кошелька в "Wallet and worker template"
(`<NEW_WALLET>.%WORKER_NAME%`) и новый пароль от пула в Pass, затем сохраните и примените его. Имя воркера — это имя
рига в HiveOS (или `-w <RIG_NAME>` в Extra config arguments).

## Прокси (необязательно)

Майнер подключается к пулу напрямую. Если в вашей сети нужен прокси:

```bash
# Linux (запоминается до изменения)
./thenewminer --proxy <IP>[:<PORT>]            # TCP-ретранслятор (порт 443, если не указан)
./thenewminer --proxy socks5://<HOST>:<PORT>   # SOCKS5, также socks5://<USER>:<PASS>@<HOST>:<PORT>
./thenewminer --proxy http://<HOST>:<PORT>     # HTTP CONNECT прокси
./thenewminer --proxy none                     # вернуться к прямому подключению
```

Эти команды также запускают майнер: сначала остановите майнер и добавьте `--background`, чтобы он работал в фоне.

```bat
:: Windows
TheNewMiner.bat setup -Proxy <IP>[:<PORT>]
TheNewMiner.bat setup -Proxy socks5://<HOST>:<PORT>
TheNewMiner.bat setup -Proxy http://<HOST>:<PORT>
TheNewMiner.bat setup -Proxy none
```

TLS всегда работает сквозным образом (end to end) с пулом, поэтому прокси не может прочитать соединение. В Windows
прокси-приложение, запущенное на том же ПК, обычно недоступно из WSL по адресу `127.0.0.1` (при сетевом режиме WSL по
умолчанию): используйте LAN IP этого ПК и разрешите в приложении подключения из локальной сети.

## Требования

| Параметр | Требование |
|---|---|
| GPU | NVIDIA GeForce RTX серии 30 / 40 / 50, 10 GB видеопамяти или больше. Риги с несколькими GPU: поддерживаются, майнит каждая видеокарта; в этом релизе тестировалось с одной видеокартой на машину |
| Драйвер | NVIDIA **580 или новее** (`nvidia-smi` должен работать). В Windows устанавливайте его в Windows, никогда внутри WSL |
| Linux | x86_64 с **glibc 2.34 или новее**, например Ubuntu 22.04 или новее либо Debian 12 или новее. Установщик проверяет, что ему нужно, и называет всё, чего не хватает |
| Windows | Windows 10 21H2 или новее, либо Windows 11, 64-bit; виртуализация (Intel VT-x / AMD SVM) включена в BIOS |
| Диск | около 20 GB свободного места |
| ОЗУ | 4 GB или больше |
| Модель | около 8.1 GiB, скачивается однократно при первом запуске (параллельно, с нескольких зеркал) и затем используется повторно |

## Обновите драйвер NVIDIA (580 или новее)

Майнеру нужен драйвер NVIDIA **580 или новее**. Проверьте, какой у вас установлен:

```bash
nvidia-smi    # в заголовке указано "Driver Version: ..."; версия должна быть 580 или новее
```

- **Ubuntu:** `sudo ubuntu-drivers install` устанавливает рекомендуемый драйвер (затем проверьте, что его версия 580 или
  новее). Чтобы выбрать версию самостоятельно:
  `sudo apt install nvidia-driver-580` (или новее; картам серии RTX 50 нужен open-вариант, например
  `nvidia-driver-580-open`). Затем перезагрузите компьютер. Используйте либо пакеты драйвера из Ubuntu, либо установщик
  NVIDIA `.run`, но никогда не смешивайте их.
- **Debian:** собственные пакеты драйвера в Debian старше 580 (535 в Debian 12, 550 в Debian 13). Установите более
  новый драйвер из репозитория NVIDIA, как описано в
  [NVIDIA Driver Installation Guide](https://docs.nvidia.com/datacenter/tesla/driver-installation-guide/debian.html)
  (руководство по установке драйвера NVIDIA), затем перезагрузите компьютер.
- **Windows:** обновите драйвер через [NVIDIA app](https://www.nvidia.com/en-us/software/nvidia-app/) (ранее GeForce
  Experience) или скачайте драйвер для своей карты с [nvidia.com](https://www.nvidia.com/en-us/drivers/) (580 или
  новее). WSL2 использует этот драйвер Windows: никогда не устанавливайте драйвер NVIDIA для Linux внутри WSL.
- **HiveOS:** от имени root (Hive Shell или SSH, а затем `sudo -i`) выполните `nvidia-driver-update --list`, чтобы
  увидеть доступные версии, затем, например, `nvidia-driver-update 595` (подойдёт любая версия 580 или новее), затем
  `sreboot`.

## Частые вопросы

**Windows пишет «Система Windows защитила ваш компьютер» / «Неизвестный издатель».**
Комплект не подписан цифровой подписью. Нажмите **Подробнее**, затем **Выполнить в любом случае**.

**Мой антивирус помечает или удаляет майнер.**
Microsoft Defender и другие антивирусы часто помечают майнеры криптовалют как «потенциально нежелательные приложения»,
даже легитимный майнер, который вы сами решили запустить, потому что вредоносные программы часто прячут майнеры. Если
файл помещён в карантин, откройте «Безопасность Windows» › «Защита от вирусов и угроз» › «Журнал защиты», выберите
элемент TheNewMiner и нажмите **Разрешить** (или добавьте распакованную папку в «Исключения»). Делайте это только для
пакета, скачанного с этой страницы, у которого совпадает SHA-256.

**Первый запуск занимает много времени.**
При первом запуске скачивается модель размером ~8.1 GiB и выполняется самопроверка GPU на вашей видеокарте; в Windows
также может настраиваться WSL2. Это происходит только один раз. Последующие запуски начинают майнить гораздо быстрее.

**Майнер сообщает, что пул отклонил кошелёк / пароль.**
Проверьте адрес кошелька и пароль от пула (аккаунт должен существовать на сайте пула), затем запустите майнер снова:
Linux `./thenewminer -u <YOUR_WALLET> -p '<YOUR_POOL_PASSWORD>'`, Windows `TheNewMiner.bat setup`. Сам майнер не
повторяет попытки с неверными учётными данными.

**Идёт ли майнинг? Где логи?**
Linux: `./thenewminer --status`, `./thenewminer --logs` или файл `thenewminer/.miner/thenewminer.log`.
Windows: `TheNewMiner.bat status` и `TheNewMiner.bat logs`.

**Моя RTX 3080 (10 GB) в Windows майнит гораздо медленнее, чем в Linux.**
В Windows видеопамять делят другие программы. См. [Устранение неполадок в Windows](WINDOWS-TROUBLESHOOTING.ru.md):
закройте браузеры с аппаратным ускорением и Docker Desktop.
