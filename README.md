# HiveOS test package (EXPERIMENTAL)

This branch holds a HiveOS custom-miner package for **testing only**. It is not a release.
The released downloads are on the `main` branch: https://github.com/ngasuka855/TheNewMiner

- Package: `thenewminer-0.1.44_r4.tar.gz` (sha256 in `thenewminer-0.1.44_r4.tar.gz.sha256`)
- HiveOS Flight Sheet → Miner: Custom → Installation URL:
  `https://github.com/ngasuka855/TheNewMiner/raw/hiveos-test/thenewminer-0.1.44_r4.tar.gz`
- Requirements: HiveOS on an Ubuntu 22.04 (or newer) base (`ldd --version` must show 2.34 or newer), NVIDIA driver 580 or newer, about 12 GB free disk.
